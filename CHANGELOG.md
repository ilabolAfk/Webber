### Планируется

- История посещений с поиском

## [1.0.0] — 2026-10-09

Первый публичный релиз.

### Добавлено

- **Вкладки** — открытие, закрытие, перемещение, favicon сайта, крестик закрытия.
- **Адресная строка** — распознаёт URL и поисковые запросы, поиск идёт в выбранной системе.
- **5 поисковых систем** на выбор: Google, DuckDuckGo, Bing, Brave Search, Яндекс.
  - Индикатор приватности **«СЛЕДИТ» / «НЕ СЛЕДИТ»** рядом с каждой системой.
  - Выбор сохраняется в конфиг.
  - Экран выбора показывается при первом запуске.
- **3 темы оформления**:
  - Тёмная (`fa5s.moon`)
  - Светлая (`fa5s.sun`)
  - Полночь (`fa5s.star`)
  - Переключение через меню, сохранение между запусками.
- **Менеджер загрузок**:
  - Прогресс-бар с процентами и объёмом.
  - Пауза / возобновление / отмена.
  - Открытие файла и показ в системной папке.
  - Индикатор типа файла по расширению (архив, PDF, видео, аудио, изображение, код).
- **Режим инкогнито** — отдельное окно с off-the-record профилем:
  - Cookies, кэш и история не пишутся на диск.
  - Фиолетовые акценты в интерфейсе.
  - Уведомление при открытии.
- **Фоновые задачи** через `QThreadPool` (`workers.py`):
  - Сохранение конфига.
  - Открытие файлов и папок в системном проводнике.
- **Font Awesome 5 иконки** через `qtawesome` во всех элементах интерфейса.
- **Собственная иконка приложения** (`icon.ico`) — в таскбаре, заголовках окон, диалогах.
- **Горячие клавиши**:
  - `Ctrl+T` — новая вкладка
  - `Ctrl+W` — закрыть вкладку
  - `Ctrl+L` — фокус на адресную строку
  - `Ctrl+R` / `F5` — обновить
  - `Alt+←` / `Alt+→` — назад / вперёд
  - `Ctrl+J` — менеджер загрузок
  - `Ctrl+Shift+N` — новое окно инкогнито
  - `Ctrl+Q` — выход
- **Меню** (иконка `fa5s.bars` в тулбаре):
  - Новая / закрыть вкладку
  - Домашняя страница, обновить
  - Загрузки
  - Тема (подменю)
  - Новое окно инкогнито
  - Смена поисковой системы
  - Инструменты разработчика
  - Исходный код на GitHub
  - О Webber
  - Выход
- **Сборка в `.exe`** через PyInstaller:
  - `build.bat` — папка `--onedir` (рекомендуется)
  - `build_onefile.bat` — один файл `--onefile` (опционально)
  - Поддержка QtWebEngine, ICU, `QtWebEngineProcess.exe`, шрифтов Font Awesome.
- **Документация**:
  - `README.md` с полным описанием, скриншотами, бейджами, инструкцией по сборке.
  - `LICENSE` — GPL-3.0.

### Технические детали

- **PyQt6** 6.11 — UI-фреймворк.
- **QtWebEngine** 6.11 — Chromium **118+** (современный рендеринг сайтов).
- **qtawesome** 1.4 — Font Awesome 5 иконки.
- **Python** 3.10+ (тестировалось на 3.12).
- **Платформы:** Windows / Linux / macOS.
- **Конфиг:** `~/.webber_config.json` — хранит тему, поисковик и папку загрузок.
- **Архитектура потоков:**
  - UI-поток — виджеты и обработчики сигналов QtWebEngine.
  - Chromium-процессы — рендеринг и загрузки (управляет QtWebEngine).
  - `QThreadPool` — сохранение конфига и открытие файлов.

### Известные ограничения

- Chromium 118 не поддерживает самые новые CSS-фичи (`@scope`, `:has()` частично).
- Windows Defender может ложно срабатывать на собранный `.exe` (эвристика PyInstaller).
- Файлы, скачанные в режиме инкогнито, сохраняются в обычную папку `~/Downloads` (как в Chrome).
- `--onefile` сборка стартует 5–15 секунд из-за распаковки QtWebEngine.

- **Удалено** — удалённые функции.
- **Исправлено** — багфиксы.
